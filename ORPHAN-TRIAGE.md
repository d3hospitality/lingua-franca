`node tools/audit-deps.js` (in d3-agent-world) flagged 5 orphan source files in
this repo. Each was manually confirmed against static imports, dynamic
`import()`, HTML `<script src>`, and exported-symbol usage. Resolution below.

## Resolved — phantom orphans (tool fix, no longer flagged)

- `lingua-franca-api/api/suggest.js`
- `lingua-franca-api/api/transcribe.js`

These are **live Vercel serverless functions** (project `lingua-franca-api`,
linked via `.vercel/project.json`). They were mis-flagged because the auditor
only treated a nested dir as a separate project when it carried a
`package.json` — and this Vercel functions dir (correctly) has none. Fixed two
ways:

1. Added `lingua-franca-api/vercel.json` — an explicit Vercel config marker
   (also sets sane `maxDuration`: transcribe 60s, suggest 30s).
2. Extended `audit-deps.js` to treat a nested `vercel.json` **or** `.vercel/`
   directory as a project boundary (with regression tests). Phantom orphans gone.
